VNLRY uploader 私隱權政策

最後更新：2026-10-02

VNLRY uploader 係 YouTube 頻道「陪入夢聲小說」(@vn-lry) 擁有人自用嘅工具，只用嚟管理自己頻道：上載影片、更改影片設定、回覆留言同查看頻道數據。

VNLRY uploader's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. This tool is used only by the channel owner to manage their own channel; no user data is collected, sold or shared.
